# ctab - タブタイトルを [surface番号] を保ったまま変更

引数があればそれをタイトルとして、次を1回の bash で実行せよ:

```bash
ctab "<タイトル>" ["<説明>"]
```

- 引数が「タイトル、説明は〜」のような自然文なら、タイトル部分と説明部分に切り分けて第1・第2引数へ渡す
- **引数なしなら** まず `ctab` を引数なしで実行して現状を表示し、直近の作業内容から2〜4語（役割が先頭）のタイトルを決めて提案してから適用する
- 先頭の `[NNN]` はスクリプトが維持する。**自分で番号を付けたり外したりしない**
- 結果を1行で報告
- **書き込み前の中止**（番号を解決できない／渡した番号が実際と違う）なら、番号を外したタイトルで1回だけやり直す。勝手に番号を付け直さない
- **書き込み後の確認失敗**（「rename は実行済み」と出た場合）は**再実行しない**。既に書き込まれているので、目視確認をオペレーターに促す

タイトルの付け方と番号解決の詳細は `ctab` skill を参照。
